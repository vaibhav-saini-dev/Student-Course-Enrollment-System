# Student-Course-Enrollment-System
A command-line Java application that connected to an Oracle database to search courses, enroll students, drop courses, and view schedules

Compiling & Running
- To compile Student.java, run javac -cp ".:ojdbc17.jar" Student.java to generate the Student.class
  file, and then run java -cp ".:ojdbc17.jar" to run the program.
